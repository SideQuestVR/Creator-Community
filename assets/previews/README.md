# Catalogue Preview Illustrations

`editor-tools.svg` is an original category illustration, not a screenshot or
evidence of a particular plugin's interface. `editor-tools.png` is its 960 x 540
raster export for clients, including the Unity Editor, that cannot display SVG.

These assets are MIT licensed under the repository licence. Listings can use
`assets/previews/editor-tools.png` when an author has not supplied a screenshot.
An author's own accurate preview should replace it when available.
